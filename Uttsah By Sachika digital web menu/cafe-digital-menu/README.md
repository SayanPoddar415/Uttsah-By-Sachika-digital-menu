# Uttsah By Sachika — Responsive Cafe Digital Menu Website

A responsive, zero-dependency Digital Menu Web Application built with **HTML5**, **CSS3**, and **Vanilla JavaScript**.

## What's Included
- **Sticky Navigation Header:** Keeps the cafe logo and wishlist button fixed and accessible at the top while scrolling.
- **Dish-Matched Food Images:** Every menu item in `js/menu-data.js` has a curated food image URL with automatic fallback to `assets/food/default.svg`.
- **Dynamic Category Filtering:** Instant client-side filtering across `All Items`, `Breakfast`, `Coffee`, `Pizza`, `Burgers`, `Desserts`, and `Beverages`.
- **Session-Based Wishlist (`sessionStorage`):** Save/remove favourites, prevent duplicates, view totals, and retain items during the active browsing session.
